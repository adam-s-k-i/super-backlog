# Router v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the two-tier, family-following model router with a four-tier router (light / standard / strong / top per harness) that writes one subagent per tier with a fixed model, is maintained by `sbl update`, and renders the managed block's model examples from `.super-backlog/models.json`.

**Architecture:** `src/models/config.ts` loads and normalizes the version 2 config (migrating v1 in memory). `src/models/apply.ts` is the only code path that writes router files: it migrates the config file, writes the four agent files per router-installed harness via `src/models/agents.ts`, removes v1 leftovers (agents, plugin, SessionStart hook), and optionally re-injects the managed block, whose example paragraph is produced by `src/models/render.ts`. The CLI (`sbl models`), `sbl init --models`, `sbl update` and the dashboard API all call `applyRouter`.

**Tech Stack:** TypeScript ESM (NodeNext, strict), Node >= 20, Vitest, Windows (Git Bash for commands).

Spec decisions made by this plan (where the spec left a choice open):

1. "Wrap at 80 columns" means no rendered line is longer than 79 characters; this reproduces the spec's enabled example exactly.
2. v1 migration takes the first *valid* model id (not just the first non-empty one) from `individual`, `tiers`, `resolved`.
3. A discovery whose ranking is empty counts as a failure (`null`).
4. Discovered ids are filtered through `isValidModelId` before ranking.
5. `src/models/install.ts` is kept as the config-mutator module (`setRouterEnabled`, `setRouterTier`, `saveDiscovery`).
6. Agent file content is generated in code (`renderAgentFile`); there is no agent template file.
7. A missing `model:` line is inserted right after the opening `---`; a file without frontmatter gets `---` / `model: x` / `---` prepended (and is left alone when the model is `null`).
8. OpenCode frontmatter order is `name`, `description`, `mode`, `model`.
9. Hook cleanup belongs to the Claude harness; it prints `removed legacy .claude/settings.json SessionStart hook` or a `warning:` line for unparsable settings.
10. The disabled notice prints after `set` and `discover` whenever the router is disabled afterwards.
11. `applyRouter` report lines: `migrated .super-backlog/models.json to version 2`, `normalized .super-backlog/models.json`, `created <path>`, `updated <path>`, `removed legacy <path>`, `updated AGENTS.md`.
12. An unparsable `models.json` is never rewritten by `applyRouter`; it reports `warning: .super-backlog/models.json is not valid JSON - left unchanged`.
13. A `models.json` that differs from the normalized form only by CRLF line endings is not rewritten.
14. The dashboard API adds `tiers` (effective tiers) to every response and `ok` to POST responses; a failed discovery returns `200 {ok:false, error:'discovery failed'}`.
15. `update` prepends `refresh-model-router` to the refresh actions (it is not produced by `planInit`).
16. `planInit` emits `install-model-router` before `inject-agents-block`.
17. `agentsBlockContents` normalizes the template to LF before substitution.
18. The e2e v1 → v2 migration test runs `runUpdate` in-process.
19. The `install-model-router` action calls `applyRouter` with `install: action.enabled`.
20. Block re-injection from `sbl models` and the dashboard uses the running CLI's `KIT_VERSION` for the marker.
21. Model ids ending in `:` are rejected (YAML safety), in addition to the spec's regex and length rule.

// src/models/discovery.ts
import { runCapture } from '../lib/run.js';
import { isValidModelId } from './config.js';
import { TIERS } from './defaults.js';
import type { Tier, TierModels } from './types.js';

export interface DiscoveryResult {
  discoveredAt: string;
  tiers: TierModels;
}

const LIGHT_PATTERNS = ['haiku', 'flash-lite', 'nano', '-lite', '-mini'];

/** Ordered substring preferences; earlier patterns win, the first id matching a pattern wins. */
const PREFERENCES: Record<Tier, string[]> = {
  top: ['fable', 'mythos', 'opus'],
  strong: ['opus', 'codex', 'gpt-5', '-pro'],
  standard: ['sonnet', 'flash', 'k2.5'],
  light: LIGHT_PATTERNS,
};

export function parseOpenCodeModels(output: string): string[] {
  return output
    .split('\n')
    .map((s) => s.trim())
    .filter((s) => s.length > 0 && s.includes('/'));
}

function isLightMatch(id: string): boolean {
  const lower = id.toLowerCase();
  return LIGHT_PATTERNS.some((p) => lower.includes(p));
}

function pick(available: string[], tier: Tier): string | undefined {
  const pool = tier === 'light' ? available : available.filter((id) => !isLightMatch(id));
  for (const pattern of PREFERENCES[tier]) {
    const hit = pool.find((id) => id.toLowerCase().includes(pattern));
    if (hit !== undefined) return hit;
  }
  return undefined;
}

export function rankFourTiers(available: string[]): TierModels {
  const picks: TierModels = {
    light: pick(available, 'light'),
    standard: pick(available, 'standard'),
    strong: pick(available, 'strong'),
  };
  picks.top = pick(available, 'top') ?? picks.strong;
  const out: TierModels = {};
  for (const tier of TIERS) {
    const id = picks[tier];
    if (id !== undefined) out[tier] = id;
  }
  return out;
}

export async function discoverModels(cwd: string): Promise<DiscoveryResult | null> {
  try {
    const result = runCapture('opencode', ['models'], cwd);
    if (result.status !== 0) return null;
    const available = parseOpenCodeModels(result.stdout).filter(isValidModelId);
    if (available.length === 0) return null;
    const tiers = rankFourTiers(available);
    if (Object.keys(tiers).length === 0) return null;
    return { discoveredAt: new Date().toISOString(), tiers };
  } catch {
    return null;
  }
}

type ReportLine = { verdict: 'removed' | 'kept' | 'skipped' | 'error'; label: string };

export type HookStripResult = 'missing' | 'invalid' | 'none' | 'none-owned' | 'removed';

const HOOK_REPORT: Record<HookStripResult, ReportLine> = {
  missing: { verdict: 'skipped', label: '.claude/settings.json model-router hook (not found)' },
  invalid: { verdict: 'skipped', label: '.claude/settings.json (not valid JSON)' },
  none: { verdict: 'skipped', label: '.claude/settings.json SessionStart hook (none)' },
  'none-owned': { verdict: 'skipped', label: '.claude/settings.json SessionStart hook (none owned)' },
  removed: { verdict: 'removed', label: '.claude/settings.json SessionStart hook' },
};

/** A SessionStart entry is ours when one of its command hooks runs cc-session-hook.js. */
function ownsEntry(entry: unknown): boolean {
  if (entry === null || typeof entry !== 'object') return false;
  const hooks = (entry as { hooks?: unknown }).hooks;
  if (!Array.isArray(hooks)) return false;
  return hooks.some((h) => {
    if (h === null || typeof h !== 'object') return false;
    const { type, args } = h as { type?: unknown; args?: unknown };
    return type === 'command' && Array.isArray(args) && String(args[0] ?? '').includes('cc-session-hook.js');
  });
}

/** Removes the router v1 SessionStart entries from .claude/settings.json; other hooks and keys stay. Never throws on bad JSON. */
export function stripSessionHook(cwd: string): HookStripResult {
  const path = join(cwd, '.claude', 'settings.json');
  if (!existsSync(path)) return 'missing';
  let settings: { hooks?: unknown };
  try {
    const parsed: unknown = JSON.parse(readFileSync(path, 'utf8'));
    if (parsed === null || typeof parsed !== 'object' || Array.isArray(parsed)) return 'invalid';
    settings = parsed as { hooks?: unknown };
  } catch {
    return 'invalid';
  }
  const hooks = settings.hooks;
  if (hooks === null || typeof hooks !== 'object' || Array.isArray(hooks)) return 'none';
  const hookMap = hooks as Record<string, unknown>;
  const sessionStart = hookMap['SessionStart'];
  if (!Array.isArray(sessionStart) || sessionStart.length === 0) return 'none';
  const filtered = sessionStart.filter((entry) => !ownsEntry(entry));
  if (filtered.length === sessionStart.length) return 'none-owned';
  if (filtered.length === 0) {
    delete hookMap['SessionStart'];
    if (Object.keys(hookMap).length === 0) delete settings.hooks;
  } else {
    hookMap['SessionStart'] = filtered;
  }
  atomicWrite(path, `${JSON.stringify(settings, null, 2)}\n`);
  return 'removed';
}

export function uninstallModelRouter(cwd: string, report: ReportLine[]): void {
  for (const rel of ROUTER_FILES) {
    const abs = join(cwd, rel);
    if (!existsSync(abs)) {
      report.push({ verdict: 'skipped', label: `${rel} (not found)` });
      continue;
    }
    rmSync(abs, { force: true });
    report.push({ verdict: 'removed', label: rel });
  }

  // Remove .super-backlog directory if it is now empty
  const dir = join(cwd, '.super-backlog');
  if (existsSync(dir)) {
    try {
      const remaining = readdirSync(dir);
      if (remaining.length === 0) {
        rmSync(dir, { recursive: true, force: true });
        report.push({ verdict: 'removed', label: '.super-backlog/' });
      } else {
        report.push({ verdict: 'kept', label: '.super-backlog/ (contains other files)' });
      }
    } catch {
      // ignore race conditions
    }
  }

  report.push({ ...HOOK_REPORT[stripSessionHook(cwd)] });
}

import { existsSync, readFileSync, rmSync } from 'node:fs';
import { join } from 'node:path';
import { atomicWrite } from '../lib/atomic.js';
import { detectEol } from '../lib/eol.js';
import { claudeModel } from './config.js';
import { TIERS } from './defaults.js';
import type { Harness, RouterConfig, Tier } from './types.js';
import { stripSessionHook } from './uninstall.js';

export const AGENT_DIRS: Record<Harness, string> = {
  claude: '.claude/agents',
  opencode: '.opencode/agents',
};
export const LEGACY_AGENT_FILES: readonly string[] = ['sbl-worker.md', 'sbl-worker-cheap.md'];
export const LEGACY_PLUGIN = '.opencode/plugins/sbl-model-router.js';

const TIER_LABELS: Record<Tier, string> = { light: 'Light', standard: 'Standard', strong: 'Strong', top: 'Top' };

const TIER_DESCRIPTIONS: Record<Tier, string> = {
  light: 'purely mechanical work such as searching, listing, extracting and reformatting.',
  standard: 'clearly specified routine work such as research, summaries, routine code, tests and documentation.',
  strong: 'demanding work with clear boundaries such as complex implementation, debugging and reviews.',
  top: 'analysis, design, architecture and every decision where a mistake is costly; everything backlog/docs/critical-areas.md lists as critical.',
};

const AGENT_BODY =
  'Work on the delegated task exactly as briefed. Return the result with evidence (paths, sources, numbers), no raw logs.';

export function agentFileName(tier: Tier): string {
  return `sbl-${tier}.md`;
}

/** POSIX path relative to the project root, used both for writing and for report lines. */
export function agentPath(harness: Harness, tier: Tier): string {
  return `${AGENT_DIRS[harness]}/${agentFileName(tier)}`;
}

/** The model written into an agent file; null means "no model line" (OpenCode only). */
export function agentModel(cfg: RouterConfig, harness: Harness, tier: Tier): string | null {
  if (harness === 'claude') return cfg.enabled ? claudeModel(cfg, tier) : 'inherit';
  return cfg.enabled ? (cfg.tiers.opencode?.[tier] ?? null) : null;
}

export function renderAgentFile(harness: Harness, tier: Tier, model: string | null): string {
  const lines = ['---', `name: sbl-${tier}`, `description: ${TIER_LABELS[tier]} tier — ${TIER_DESCRIPTIONS[tier]}`];
  if (harness === 'opencode') lines.push('mode: subagent');
  if (model !== null) lines.push(`model: ${model}`);
  lines.push('---', AGENT_BODY, '');
  return lines.join('\n');
}

/** Replaces, inserts (after the opening ---) or removes (null) the frontmatter `model:` line; keeps everything else and the file's EOL. */
export function setModelLine(content: string, model: string | null): string {
  const eol = detectEol(content);
  const lines = content.split(/\r?\n/);
  if (lines[0] !== '---') {
    return model === null ? content : ['---', `model: ${model}`, '---', ...lines].join(eol);
  }
  let close = lines.indexOf('---', 1);
  if (close === -1) close = lines.length;
  const found = lines.slice(1, close).findIndex((l) => l.startsWith('model:'));
  const at = found === -1 ? -1 : found + 1;
  if (model === null) {
    if (at !== -1) lines.splice(at, 1);
  } else if (at !== -1) {
    lines[at] = `model: ${model}`;
  } else {
    lines.splice(1, 0, `model: ${model}`);
  }
  return lines.join(eol);
}

export type AgentWrite = 'created' | 'updated' | 'unchanged';

export function writeAgentFile(cwd: string, harness: Harness, tier: Tier, model: string | null): AgentWrite {
  const abs = join(cwd, agentPath(harness, tier));
  if (!existsSync(abs)) {
    atomicWrite(abs, renderAgentFile(harness, tier, model));
    return 'created';
  }
  const current = readFileSync(abs, 'utf8');
  const next = setModelLine(current, model);
  if (next === current) return 'unchanged';
  atomicWrite(abs, next);
  return 'updated';
}

/** Any v2 or v1 agent file, or (OpenCode) the v1 plugin. */
export function isRouterInstalled(cwd: string, harness: Harness): boolean {
  const names = [...TIERS.map(agentFileName), ...LEGACY_AGENT_FILES];
  if (names.some((n) => existsSync(join(cwd, AGENT_DIRS[harness], n)))) return true;
  return harness === 'opencode' && existsSync(join(cwd, LEGACY_PLUGIN));
}

/** Removes router v1 leftovers for one harness; one report line per removal. */
export function cleanLegacy(cwd: string, harness: Harness): string[] {
  const lines: string[] = [];
  const rels = LEGACY_AGENT_FILES.map((f) => `${AGENT_DIRS[harness]}/${f}`);
  if (harness === 'opencode') rels.push(LEGACY_PLUGIN);
  for (const rel of rels) {
    const abs = join(cwd, rel);
    if (!existsSync(abs)) continue;
    rmSync(abs, { force: true });
    lines.push(`removed legacy ${rel}`);
  }
  if (harness === 'claude') {
    const hook = stripSessionHook(cwd);
    if (hook === 'removed') lines.push('removed legacy .claude/settings.json SessionStart hook');
    if (hook === 'invalid') lines.push('warning: .claude/settings.json is not valid JSON - legacy SessionStart hook left in place');
  }
  return lines;
}

// src/models/apply.ts
import { existsSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import { agentsBlockContents } from '../init/planner.js';
import { atomicWrite } from '../lib/atomic.js';
import { injectBlock, stripOwned } from '../lib/markers.js';
import { agentModel, agentPath, cleanLegacy, isRouterInstalled, writeAgentFile } from './agents.js';
import { loadConfig, serializeConfig } from './config.js';
import { CONFIG_PATH, HARNESSES, TIERS } from './defaults.js';

export interface ApplyOptions {
  install: boolean;
  block: boolean;
  version: string;
}

/** Writes models.json back when it differs from its normalized form. Unparsable files are never touched. */
function migrateFile(cwd: string): string[] {
  const path = join(cwd, CONFIG_PATH);
  if (!existsSync(path)) return [];
  const raw = readFileSync(path, 'utf8');
  let parsed: unknown;
  try {
    parsed = JSON.parse(raw);
  } catch {
    return [`warning: ${CONFIG_PATH} is not valid JSON - left unchanged`];
  }
  const normalized = serializeConfig(loadConfig(cwd));
  if (raw.replace(/\r\n/g, '\n') === normalized) return [];
  atomicWrite(path, normalized);
  const version = parsed !== null && typeof parsed === 'object' ? (parsed as { version?: unknown }).version : undefined;
  return [version === 2 ? `normalized ${CONFIG_PATH}` : `migrated ${CONFIG_PATH} to version 2`];
}

function refreshBlock(cwd: string, version: string): string[] {
  const path = join(cwd, 'AGENTS.md');
  if (!existsSync(path)) return [];
  const current = readFileSync(path, 'utf8');
  if (!stripOwned(current).removed) return [];
  const injected = injectBlock(current, version, agentsBlockContents(version));
  if (injected.action === 'unchanged') return [];
  atomicWrite(path, injected.content);
  return ['updated AGENTS.md'];
}

/** The only code path that writes router files. Returns the report lines. */
export function applyRouter(cwd: string, opts: ApplyOptions): string[] {
  const lines = migrateFile(cwd);
  const cfg = loadConfig(cwd);
  const harnesses = opts.install ? [...HARNESSES] : HARNESSES.filter((h) => isRouterInstalled(cwd, h));
  for (const harness of harnesses) {
    for (const tier of TIERS) {
      const result = writeAgentFile(cwd, harness, tier, agentModel(cfg, harness, tier));
      if (result !== 'unchanged') lines.push(`${result} ${agentPath(harness, tier)}`);
    }
    lines.push(...cleanLegacy(cwd, harness));
  }
  if (opts.block) lines.push(...refreshBlock(cwd, opts.version));
  return lines;
}

const MODEL_RULE =
  'allowed: letters, digits and . _ : / @ + -, starting with a letter or digit, not ending with ":", at most 100 characters; "-" removes the entry';

function apply(cwd: string, install: boolean): void {
  for (const line of applyRouter(cwd, { install, block: true, version: KIT_VERSION })) console.log(line);

function runSet(cwd: string, rest: string[]): number {
  const [harness, tier, model, ...extra] = rest;
  if (harness === undefined || tier === undefined || model === undefined || extra.length > 0) {
    console.error(SET_USAGE);
    return 1;
  }
  if (!isHarness(harness)) {
    console.error(`invalid harness: ${harness} (allowed: ${HARNESSES.join(', ')})`);
    return 1;
  }
  if (!isTier(tier)) {
    console.error(`invalid tier: ${tier} (allowed: ${TIERS.join(', ')})`);
    return 1;

    return 1;

  console.log(model === '-' ? `${harness} ${tier} removed` : `${harness} ${tier} = ${model}`);
  apply(cwd, false);

  return 0;

// src/models/dashboard-api.ts
import { existsSync } from 'node:fs';
import type { IncomingMessage, ServerResponse } from 'node:http';
import { join } from 'node:path';
import { KIT_VERSION } from '../lib/version.js';
import { applyRouter } from './apply.js';
import { effectiveTiers, loadConfig } from './config.js';
import { CONFIG_PATH } from './defaults.js';
import { discoverModels } from './discovery.js';
import { saveDiscovery, setRouterEnabled } from './install.js';

function sendJson(res: ServerResponse, status: number, body: unknown): void {
  res.writeHead(status, { 'content-type': 'application/json' });
  res.end(JSON.stringify(body));
}

function snapshot(cwd: string) {
  const config = loadConfig(cwd);
  return { config, tiers: effectiveTiers(config), installed: existsSync(join(cwd, CONFIG_PATH)) };
}

function errorMessage(err: unknown): string {
  return err instanceof Error ? err.message : String(err);
}

export interface ModelApiDeps {
  discover?: typeof discoverModels;
}

export function createModelApiHandler(
  cwd: string,
  deps: ModelApiDeps = {},
): (req: IncomingMessage, res: ServerResponse) => Promise<void> {
  const discover = deps.discover ?? discoverModels;
  return async (req, res) => {
    const url = req.url ?? '/';
    const method = req.method ?? 'GET';

    if (method === 'GET' && url === '/api/models') {
      sendJson(res, 200, { ...snapshot(cwd), status: 'ok' });
      return;
    }

    if (method === 'POST' && (url === '/api/models/enable' || url === '/api/models/disable')) {
      const enabled = url === '/api/models/enable';
      try {
        setRouterEnabled(cwd, enabled);
        applyRouter(cwd, { install: enabled, block: true, version: KIT_VERSION });
        sendJson(res, 200, { ok: true, ...snapshot(cwd) });
      } catch (err) {
        sendJson(res, 500, { ok: false, message: errorMessage(err) });
      }
      return;
    }

    if (method === 'POST' && url === '/api/models/discover') {
      const result = await discover(cwd);
      if (!result) {
        sendJson(res, 200, { ok: false, error: 'discovery failed' });
        return;
      }
      try {
        saveDiscovery(cwd, result.discoveredAt, result.tiers);
        applyRouter(cwd, { install: false, block: true, version: KIT_VERSION });
        sendJson(res, 200, { ok: true, ...snapshot(cwd) });
      } catch (err) {
        sendJson(res, 500, { ok: false, message: errorMessage(err) });
      }
      return;
    }

    res.writeHead(404, { 'content-type': 'text/plain' });
    res.end('not found');
  };
}

# Model router

The model router is optional. It writes one subagent per tier — `sbl-light`, `sbl-standard`, `sbl-strong` and `sbl-top` — for Claude Code and OpenCode, each with a fixed model, and renders the model examples in the managed `AGENTS.md` block from your configuration. The block's [delegation rule](harness-support#model-tiers-and-delegation-all-harnesses) applies with or without the router.

Install it into a new project:

```bash
sbl init --models
```

`sbl models enable` installs it into an existing project.

## Configuration

The router reads `.super-backlog/models.json`:

```json
{
  "version": 2,
  "enabled": true,
  "tiers": {
    "claude": { "light": "haiku", "standard": "sonnet", "strong": "opus", "top": "fable" },
    "opencode": { "light": "opencode/gemini-3.5-flash-lite", "standard": "opencode/claude-sonnet-4-6" }
  },
  "discoveredAt": "2026-10-11T08:00:00.000Z"
}
```

- `version` is always `2`.
- `enabled` switches the router on and off. While it is `false` the configuration is kept, the block shows the release's generic examples, Claude Code agents get `model: inherit` and OpenCode agents get no `model` line.
- `tiers` holds one optional entry per harness (`claude`, `opencode`) and tier (`light`, `standard`, `strong`, `top`).
- `discoveredAt` is set by `sbl models discover`.

A model id starts with a letter or digit, contains only letters, digits and `. _ : / @ + -`, does not end with `:`, and has at most 100 characters. `sbl models set` rejects other ids; the loader drops them.

## Tiers and defaults

| Tier | Use it for | Claude Code default | OpenCode default |
| --- | --- | --- | --- |
| `light` | Purely mechanical work: searching, listing, extracting, reformatting | `haiku` | session model |
| `standard` | Clearly specified routine work: research, summaries, routine code, tests, documentation | `sonnet` | session model |
| `strong` | Demanding work with clear boundaries: complex implementation, debugging, reviews | `opus` | session model |
| `top` | Analysis, design, architecture, costly decisions, everything the [project profile](project-profile) lists as critical | `fable` | session model |

The Claude Code defaults are aliases that track Anthropic's current models. OpenCode has no defaults: a tier without a model gets no `model` line, and OpenCode uses the session model.

## Commands

| Command | Effect |
| --- | --- |
| `sbl models` / `sbl models show` | Print the normalized configuration as JSON. |
| `sbl models enable` | Set `enabled: true` and install the agents for both harnesses. |
| `sbl models disable` | Set `enabled: false` and rewrite the agents. |
| `sbl models set <harness> <tier> <model>` | Set one tier. The model `-` removes the entry. |
| `sbl models discover` | Rank the models that `opencode models` lists into the four OpenCode tiers and save them. |

`set` and `discover` never change `enabled`. On a project without `models.json` they create it disabled and print a reminder to run `sbl models enable`.

Every command that changes the configuration rewrites the agent files and the managed block in `AGENTS.md`. `sbl update` keeps installed router files current; it never installs them.

### Discovery

`sbl models discover` matches substrings of the listed ids, case-insensitively. Earlier patterns win; within a pattern the first listed id wins.

| Tier | Preferences, in order |
| --- | --- |
| `top` | `fable`, `mythos`, `opus` (falls back to the `strong` pick) |
| `strong` | `opus`, `codex`, `gpt-5`, `-pro` |
| `standard` | `sonnet`, `flash`, `k2.5` |
| `light` | `haiku`, `flash-lite`, `nano`, `-lite`, `-mini` |

Ids that match a `light` pattern are never picked for the other tiers. Discovery replaces the previous OpenCode tiers. Claude Code has no discovery.

## Files written

| File | Written when |
| --- | --- |
| `.super-backlog/models.json` | Any `sbl models` command that changes the configuration, `sbl init --models`, or `sbl update` migrating a version 1 file |
| `.claude/agents/sbl-<tier>.md` | The router is installed for Claude Code |
| `.opencode/agents/sbl-<tier>.md` | The router is installed for OpenCode (with `mode: subagent`) |

An existing agent file keeps your edits to its description and body; only its `model:` line is replaced, inserted or removed.

## Migration from router v1

Router v1 had two tiers (`workhorse`, `budget`), a `SessionStart` hook for Claude Code and a `chat.params` plugin for OpenCode. The first `sbl update` after upgrading:

- rewrites `models.json` as version 2: `workhorse` becomes the OpenCode `standard` tier, `budget` the OpenCode `light` tier, and `mode` and `families` are dropped. Claude tiers start from the defaults;
- writes the eight `sbl-<tier>.md` agents with concrete models;
- removes `sbl-worker.md`, `sbl-worker-cheap.md`, `.opencode/plugins/sbl-model-router.js` and the router's `SessionStart` entry in `.claude/settings.json`. Other hooks and settings stay.

Each removal prints one `removed legacy <path>` line.

## Dashboard

The **Model Router** button in the dashboard opens a dialog with the router state, an enable / disable toggle, a discover button and a table of the four tiers for Claude Code and OpenCode. Unset OpenCode tiers show "session model". Tiers are edited on the command line; the dialog offers `sbl models set <harness> <tier> <model>` to copy.

## Uninstall

`sbl uninstall` removes `models.json`, the agent files of both router generations and the router's `SessionStart` entry.
